# LeetCode Solutions

My solutions to LeetCode problems.

## Languages

- Python (`solution.py`)
- C (`solution.c`)

## Repository Structure

Each problem has its own folder, named `<question number>. <question name>`, containing a Python and a C solution:

```
leetcode/
├── 1. Two Sum/
│   ├── solution.py
│   └── solution.c
├── 2. Add Two Numbers/
│   ├── solution.py
│   └── solution.c
└── ...
```

## Running a Solution

**Python**

```bash
python3 solution.py
```

**C**

```bash
gcc solution.c
./a.out
```
